# Akshay Sarwad — Java Full Stack Developer Portfolio

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive dark professional design
- `script.js` — mobile navigation, scroll reveal animations and current year

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy to Netlify
1. Open Netlify.
2. Choose **Add new site → Deploy manually**.
3. Drag the project folder into the deploy area.
4. Your portfolio will be published with a Netlify URL.

## Add your resume
If you want a Resume button, place your PDF in this folder as `resume.pdf` and add:
`<a href="resume.pdf" download>Download Resume</a>`

## Customize
Update links, project GitHub URLs, certificates, and profile content in `index.html`.
